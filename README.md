# まいにち家計簿 v3

iPhoneで生活費をコントロールするための、個人用・静的Webアプリです。サーバー、ログイン、外部DB、外部ライブラリは使いません。

## 使い始める

`index.html` をブラウザで開くか、GitHub Pagesで公開して使います。支出や設定は、開いたブラウザの `localStorage` に保存されます。

最初に「設定」で生活費・家飲み・タバコ予算を確認し、「入力」から支出を登録してください。登録後は、同じ内容をクイック入力として保存できます。

ChatGPTでレシートや利用明細を読み取った場合は、「入力」→「ChatGPTの読み取り結果を取り込む」からCSV形式の結果を貼り付け、内容を確認してまとめて登録できます。データ元は「ChatGPT読み取り」「楽天カード」「レシート」から選べます。

v2.1では、iPhone Safariに古いCSS・JavaScriptが残らないよう読み込みURLを更新し、取り込みプレビューの日付欄をSafari固有の表示に依存しない形式に変更しました。カテゴリ編集では、現在設定している大カテゴリの生活費・固定費・全体の月予算合計を表示します。支出入力中に新しいカテゴリも追加できます。「今日使える金額」は、水道・光熱費と固定費を除いた日常費の残りを、今日から月末までの日数で割って表示します。

v2.2では、CSV取り込み後の明細プレビューをiPhoneで確認しやすい一覧型UIに変更しました。各明細は通常時に日付・金額・カテゴリ・メモをコンパクトに表示し、必要な行だけ展開して編集できます。また、入力中やプレビュー中に、小カテゴリ追加・大カテゴリ追加を選べるカテゴリ追加動線を追加しました。取り込み後は、取り込んだ明細の中で一番新しい日付の月を明細画面に表示します。登録済み明細との重複候補とCSV内だけの重複候補も分けて表示します。

v2.3では、iPhone Safariで明細プレビューの編集フォームがカード内に隠れる問題を修正しました。編集フォームをカード直下の独立したパネルとして表示し、日付・金額・カテゴリ・メモを縦並びで確実に編集できるようにしました。

v2.4では、支出入力の小カテゴリをプルダウンから常時表示の選択ボタンへ変更しました。大カテゴリを選ぶと対応する小カテゴリが一覧表示され、1タップで選択できます。

v2.5では、食費カード内に「一般食費＋仕事中食費」、日用品カード内に「タバコ」の月・週ミニ進捗を追加しました。独立していたタバコ進捗カードは廃止しています。また、「特別な支出」を予算なしの第3グループとして追加し、生活費の残り・今日使える金額・生活費内訳から分離しました。既存の「ふるさと納税」カテゴリは初回読み込み時に支出明細を残したまま特別な支出へ移行します。

v3では、食費カード内のミニ進捗を「家飲み以外の食費」へ拡張しました。小カテゴリ名を限定せず、食費に属する支出のうち家飲みだけを除外して集計するため、一般食費・仕事中食費・今後追加する小カテゴリも自動的に月・週進捗へ反映されます。

## GitHub Pagesで公開する

1. このフォルダのファイルをGitHubリポジトリの公開ブランチへ保存します。
2. GitHubのリポジトリで `Settings` → `Pages` を開きます。
3. `Deploy from a branch` を選び、公開ブランチ（通常は `main`）と `/ (root)` を指定して保存します。
4. 表示されたURLをiPhoneのSafariで開きます。
5. Safariの共有ボタンから「ホーム画面に追加」すると、アプリのように起動できます。

## データについて

- データは端末・ブラウザごとに保存され、端末間で自動同期されません。
- Safariの履歴・Webサイトデータを消すと、家計簿データも消える場合があります。
- 定期的に「設定」→「JSONバックアップ」を保存してください。
- CSVは明細の持ち出し用、JSONはカテゴリや予算を含む完全バックアップ用です。

## ファイル

- `index.html`: 4画面と各モーダルの構造
- `style.css`: iPhone向けレイアウトとデザイン
- `app.js`: 保存、集計、編集、CSV、バックアップ処理
- `tests/smoke-test.mjs`: 主要操作の自動スモークテスト
